### Specification D.1: Protocol Details

#### Message Format

All messages follow a consistent format with the following fields:

1. **Header**: Contains metadata about the message
2. **Body**: Contains the actual message content
3. **Footer**: Contains message integrity information
4. **Signature**: Cryptographic signature for verification

#### Header Structure

The header contains the following mandatory fields:

- **Version**: Protocol version number
- **Timestamp**: Message creation timestamp
- **Message ID**: Unique message identifier
- **Source ID**: Identifier of the message source
- **Destination ID**: Identifier of the message destination
- **Priority**: Message priority level (0-9)
- **TTL**: Time-to-live for message validity

#### Body Structure

The body structure varies based on message type but always includes:

- **Type**: Message type identifier
- **Payload**: Message-specific payload data
- **Encoding**: Encoding scheme for payload
- **Compression**: Compression algorithm used
- **Checksum**: Payload checksum for integrity
