# Macro: Jira Issue (Unsupported)

This fixture demonstrates a Confluence Jira macro, which is not authorable from Markdown in VERSION-TWO. It is represented as a raw HTML block.

<ac:structured-macro ac:name="jira">
  <ac:parameter ac:name="key">PROJ-123</ac:parameter>
  <ac:parameter ac:name="server">Default Jira</ac:parameter>
</ac:structured-macro>

This Jira issue macro would display issue details from the Jira integration.
